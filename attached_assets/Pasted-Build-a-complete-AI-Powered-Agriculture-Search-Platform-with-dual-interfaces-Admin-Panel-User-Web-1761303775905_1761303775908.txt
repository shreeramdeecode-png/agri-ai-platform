Build a complete AI-Powered Agriculture Search Platform with dual interfaces (Admin Panel + User Website) using the uploaded BRD document as the specification.
PROJECT SETUP
Tech Stack:

Frontend: React + Material-UI + Tailwind CSS
Backend: Node.js + Express.js
Database: Replit PostgreSQL
Auth: JWT-based authentication
AI: OpenAI GPT-4o/Vision API

Project Structure:
/
├── client/          # React frontend (Vite)
├── server/          # Express backend
├── uploads/         # File storage
└── .env            # Environment variables
```

## **DEVELOPMENT PHASES**

### **PHASE 1: Project Initialization**
1. Set up monorepo structure with client and server folders
2. Initialize React app with Vite in `/client` folder
3. Initialize Express app in `/server` folder
4. Configure Replit PostgreSQL connection
5. Create `.env` file with required variables:
```
   DATABASE_URL=your_replit_postgres_url
   JWT_SECRET=your_jwt_secret
   OPENAI_API_KEY=your_openai_key
   PORT=3000
```

### **PHASE 2: Database Schema**
Create PostgreSQL tables as per BRD:
- users (id, email, password_hash, full_name, role, is_active, created_at, updated_at)
- documents (id, user_id, filename, file_path, extracted_text, file_size, upload_date)
- images (id, user_id, filename, file_path, extracted_data, file_size, upload_date)
- search_history (id, user_id, query, extracted_params, source_type, results, agent_used, execution_time, created_at)
- api_settings (id, key_name, key_value, is_active, updated_at)
- admin_logs (id, admin_id, action, target_entity, target_id, details, created_at)

### **PHASE 3: Backend API Development**
Build Express server with:
- JWT authentication middleware
- Multer for file uploads
- pdf-parse for PDF text extraction
- OpenAI API integration (GPT-4o for text, GPT-4 Vision for images)
- Router agent pattern for query classification
- Agriculture agent for API mapping
- External API connectors (FEWSNET, CHIRPS, FAOSTAT, HDX)
```
