Update this AgriSearch project to use Gemini instead of OpenAI and improve reliability.

Requirements:

1) Gemini migration
- Install: @google/generative-ai
- Create/maintain server/utils/gemini-service.ts with:
  - analyzeQuery(query) => { domain, params } (single call)
  - extractQueryIntent / classifyDomain wrappers if needed
  - searchInDocuments(query, documents, documentIds?)
  - explainPdfDocument(filename, extractedText, question?)

- Default model: process.env.GEMINI_MODEL || "gemini-2.0-flash"

- Search endpoint should support scoped PDFs via documentIds

- Add server/utils/errors.ts and route helper sendError()
